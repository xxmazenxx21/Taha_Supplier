# Flutter Home API Documentation

## Endpoint

```http
GET /home
Authorization: Bearer <CLIENT_TOKEN>
```

The endpoint has no query parameters. It uses the authenticated client ID to
build the `reordered` section.

## Authentication and response format

The endpoint requires a valid JWT with the `CLIENT` role.

Every successful response is wrapped by the global interceptor:

```json
{
  "message": "Success",
  "data": {}
}
```

## Current response shape

```json
{
  "message": "Success",
  "data": {
    "banners": [],
    "offers": [],
    "best_sellers": [],
    "suggested": [],
    "categories": [],
    "reordered": [],
    "brands": []
  }
}
```

The current implementation does not return `secondary_banner`. That field is
not present because the Banner model has no secondary-banner designation.

## Home sections

### banners

Only banners with `is_active = true` are returned.

Ordering:
1. `sort_order ASC`
2. `created_at DESC`

Each banner includes its images ordered by `sort_order ASC`. Every image also
contains its own click action fields:

```json
{
  "id": 10,
  "image_url": "/uploads/banners/home.jpg",
  "sort_order": 0,
  "click_action_type": "CATEGORY",
  "click_target_id": 5,
  "click_target_data": null
}
```

Use the banner action rules documented in `flutter.banner.txt`.

### offers

Contains up to 10 available products from visible subcategories where
`discount_price` is not null.

Products are ordered by `display_order ASC`, then `created_at DESC`.

### best_sellers

Contains up to 10 available products from visible subcategories where
`is_best_seller = true`.

Products are ordered by `review_count DESC`, then `display_order ASC`.

### suggested

Contains up to 10 available products from visible subcategories where
`is_new = true`.

Products are ordered by `display_order ASC`, then `created_at DESC`.

### categories

Contains categories where `is_hidden = false`, ordered by
`display_order ASC`.

### reordered

Contains up to 10 unique available products from the authenticated client’s
previous orders. Cancelled orders with status `CANCELLED` or
`CLIENTCANCELLED` are excluded.

The most recently inserted order items are preferred. If the client has never
placed an eligible order, this array is empty.

### brands

Contains brands where `deleted_at = null`, ordered by `created_at DESC`.

## Product item shape

Product sections use the simplified product representation:

```json
{
  "id": 123,
  "name": "Coffee Beans",
  "image": "/uploads/products/coffee.jpg",
  "images": [
    "/uploads/products/coffee-gallery.jpg"
  ],
  "price": 100,
  "discount_price": 85,
  "discount_percentage": 15,
  "unit": "kg",
  "is_available": true,
  "rating": 4.5,
  "review_count": 24,
  "subcategory_id": 2,
  "subcategory_name": "Coffee",
  "brand": {
    "id": 10,
    "name": "Example Brand",
    "logo": "/uploads/brands/example.jpg"
  },
  "is_best_seller": false,
  "is_new": true
}
```

The current home service serializes product money and rating values as JSON
numbers. Image values are public backend paths; prepend the API base URL when
using them in Flutter.

## Recommended Flutter loading flow

1. Load `GET /home` after the client is authenticated.
2. Read the payload from `response.data`.
3. Render each section only when its array is non-empty.
4. Render only the first active banner images in the carousel according to
   their returned order.
5. On a banner image tap, handle its `click_action_type` as documented in
   `flutter.banner.txt`.
6. Show an empty state or hide `reordered` when it is empty.

## Error responses

- 401 Unauthorized: missing, expired, or invalid token.
- 403 Forbidden: token does not contain the CLIENT role.
- 500 Internal Server Error: unexpected server/database failure.

No query parameters or client-side IDs are required to call this endpoint.
