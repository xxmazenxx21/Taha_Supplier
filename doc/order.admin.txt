# Admin Dashboard Order API Documentation

## Base URL

All endpoints are relative to the application base URL, for example:
`http://localhost:3000`

## Global Rules

- Every request requires `Authorization: Bearer <admin-token>`.
- The authenticated user must have the `ADMIN` role.
- Responses use the global wrapper:

```json
{
  "message": "Success",
  "data": {}
}
```

- Monetary response values are rounded numbers in EGP.
- The client password is never included in the admin order response.

## Order Status Values

```text
PENDING
CONFIRMED
PROCESSING
SHIPPED
DELIVERED
CANCELLED          // cancelled by admin
CLIENTCANCELLED   // cancelled by client
```

## 1. Get All Orders

**Endpoint:** `GET /order/admin`

Returns every order, including active, cancelled, and client-cancelled orders. Results are sorted by `created_at` descending and have no filters or pagination.

```http
GET /order/admin
Authorization: Bearer <admin-token>
```

## 3. Update an Order Status

**Endpoint:** `PATCH /order/:id`

Updates the status of any existing order. This endpoint is for the admin dashboard.

### Example Request

```http
PATCH /order/42
Authorization: Bearer <admin-token>
Content-Type: application/json
```

```json
{
  "status": "CONFIRMED"
}
```

### Success Response — 200 OK

The response returns the updated order using the same order shape as `GET /order/admin`, including `items`, `shippingZone`, and the safe `user` object.

After the database update, the backend sends an `ORDER_STATUS_UPDATED` push
notification to every registered device belonging to this order's user. Push
delivery failures do not roll back the status update.

```json
{
  "message": "Success",
  "data": {
    "id": 42,
    "user_id": 7,
    "shipping_zone_id": 1,
    "status": "CONFIRMED",
    "payment_method": "CASH",
    "payment_status": "PENDING",
    "subtotal": 500,
    "discount_amount": 50,
    "shipping_fee": 25,
    "total_amount": 475,
    "delivery_address": "Mansoura, El-Gomhoria Street",
    "items": [],
    "shippingZone": {},
    "user": {}
  }
}
```

### Errors

- `400 Bad Request`: invalid order ID or invalid status.
- `401 Unauthorized`: missing or invalid token.
- `403 Forbidden`: authenticated user is not an admin.
- `404 Not Found`: `Order not found`.

### Admin Dashboard Example

```dart
Future<Map<String, dynamic>> updateOrderStatus(
  int orderId,
  String status,
) async {
  final token = await getAdminToken();

  final response = await http.patch(
    Uri.parse('$baseUrl/order/$orderId'),
    headers: {
      'Authorization': 'Bearer $token',
      'Content-Type': 'application/json',
    },
    body: jsonEncode({'status': status}),
  );

  if (response.statusCode == 200) {
    final body = jsonDecode(response.body) as Map<String, dynamic>;
    return Map<String, dynamic>.from(body['data']);
  }

  throw Exception('Failed to update order status');
}
```
