# Flutter Client Product Module Documentation

## Base URL
All endpoints are relative to the application's base URL (e.g. `http://localhost:3000`).

## Global Rules
- **Authentication:** All requests must include a valid Bearer token for a user with the `CLIENT` role.
- **Response Format:** All responses are intercepted and wrapped in a standard format:
  ```json
  {
    "message": "Success", // or error message
    "data": <actual_response_data>
  }
  ```
- **Visibility Restrictions:** Client endpoints will automatically exclude products that belong to a subcategory marked as hidden (`is_hidden: true`).

## Product Endpoints

### 1. Get All Products (Paginated & Filtered)
**Endpoint:** `GET /product`
**Roles:** `CLIENT`

Fetch a paginated, filterable, and sortable list of products. Products are simplified for the client interface, mapping the `images` relation to a flat array of URLs.

**Query Parameters (All optional):**
- `subcategory_id` (number): Filter by subcategory.
- `brand_id` (number): Filter by brand.
- `search` (string): Search in product name or brand name.
- `available` (number: 0 or 1): Filter by availability status.
- `offers` (number: 0 or 1): Returns only products with a discount price.
- `min_rating` (number): Returns products with a rating >= this value.
- `sort` (string): Options include:
  - `bestSelling`: Sorts by `is_best_seller` DESC, then `review_count` DESC.
  - `newest`: Sorts by `is_new` DESC, then `id` DESC.
  - `topRated`: Sorts by `rating` DESC.
  - `nameAsc`: Sorts alphabetically by name.
  - Default: Sorts by `display_order` ASC.
- `page` (number): Default `1`.
- `per_page` (number): Default `10`.

**Example Request:**
`GET /product?page=1&per_page=10&offers=1&sort=newest`

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": {
    "items": [
      {
        "id": 1,
        "name": "Samsung Galaxy S24",
        "image": "/uploads/products/xyz.jpg",
        "images": [
          "/uploads/products/gallery1.jpg"
        ],
        "price": 999.99,
        "discount_price": 899.99,
        "discount_percentage": 10,
        "unit": "pcs",
        "is_available": true,
        "rating": 4.5,
        "review_count": 120,
        "subcategory_id": 1,
        "subcategory_name": "Smartphones",
        "brand": {
          "id": 2,
          "name": "Samsung",
          "logo": "/uploads/brands/samsung.jpg"
        },
        "is_best_seller": true,
        "is_new": true
      }
    ],
    "page": 1,
    "per_page": 10,
    "next_page": 2,
    "last_page": 5,
    "total": 45
  }
}
```

**Errors:**
- `400 Bad Request`: Triggered if query parameter types are invalid (e.g. `page=abc`).

### 2. Quick Search Products
**Endpoint:** `GET /product/search`
**Roles:** `CLIENT`

Provides a quick search functionality, usually for a top search bar. Returns a maximum of 20 simplified products matching the query. Excludes hidden subcategories.

**Query Parameters:**
- `q` (string, required): The search keyword. Must be at least 2 characters long.

**Example Request:**
`GET /product/search?q=samsung`

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": [
    {
      "id": 1,
      "name": "Samsung Galaxy S24",
      "image": "/uploads/products/xyz.jpg",
      "images": ["/uploads/products/gallery1.jpg"],
      "price": 999.99,
      ...
    }
  ]
}
```

**Errors:**
- `400 Bad Request`: "Search query must be at least 2 characters long" (If `q` is missing or < 2 chars).

---

### 3. Get Single Product Details
**Endpoint:** `GET /product/:id`
**Roles:** `CLIENT`

Fetches comprehensive details for a single product by its ID.

**Example Request:**
`GET /product/1`

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": {
    "id": 1,
    "name": "Samsung Galaxy S24",
    ...
  }
}
```

**Errors:**
- `404 Not Found`: "Product not found" (If the ID does not exist).
- `400 Bad Request`: Validation failure if `:id` is not a number.

## Review Endpoints

### 1. Create a Review
**Endpoint:** `POST /review/:productId`
**Roles:** `CLIENT`
**Content-Type:** `application/json`

Creates a new review for the specified product. The user's ID is automatically extracted from the auth token. It updates the product's overall rating and review count inside a transaction.

**Request Parameters:**
- `productId` (number in URL): ID of the product being reviewed.

**Request Body (JSON):**
- `rating` (number, required, min 1, max 5): The rating given by the user.
- `comment` (string, optional, min length 1): Review comment/text.

**Example Request:**
```json
{
  "rating": 5,
  "comment": "Amazing product!"
}
```

**Success Response (201 Created):**
```json
{
  "message": "Success",
  "data": {
    "id": 1,
    "product_id": 1,
    "user_id": 1,
    "rating": 5,
    "comment": "Amazing product!",
    "created_at": "2026-09-19T00:00:00.000Z",
    "updated_at": "2026-09-19T00:00:00.000Z",
    "product": { ... },
    "user": {
      "id": 1,
      "name": "John Doe",
      "email": "john@example.com",
      "phone": "1234567890"
    }
  }
}
```

**Errors:**
- `400 Bad Request`: "A review for this product by this user already exists"
- `400 Bad Request`: "Product or user does not exist"

---

### 2. Update a Review
**Endpoint:** `PATCH /review/:productId/:reviewId`
**Roles:** `CLIENT`
**Content-Type:** `application/json`

Updates a specific review. The server verifies that the review actually belongs to the authenticated user. Recalculates product rating aggregates automatically.

**Request Parameters:**
- `productId` (number in URL): Product ID.
- `reviewId` (number in URL): Review ID to update.

**Request Body (JSON):**
- `rating` (number, optional, min 1, max 5)
- `comment` (string, optional, min length 1)

**Example Request:**
```json
{
  "rating": 4,
  "comment": "Changed my mind, it's good but not perfect."
}
```

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": {
    "id": 1,
    "rating": 4,
    ...
  }
}
```

**Errors:**
- `404 Not Found`: "Review not found"
- `403 Forbidden`: "You can only modify your own reviews"

---

### 3. Delete a Review
**Endpoint:** `DELETE /review/:productId/:reviewId`
**Roles:** `CLIENT`

Hard deletes a specific review. The server verifies that the review belongs to the authenticated user. Automatically recalculates the product's overall rating after deletion.

**Request Parameters:**
- `productId` (number in URL): Product ID.
- `reviewId` (number in URL): Review ID to delete.

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": {
    "id": 1,
    ... // returns deleted review data
  }
}
```

**Errors:**
- `404 Not Found`: "Review not found"
- `403 Forbidden`: "You can only delete your own reviews"
