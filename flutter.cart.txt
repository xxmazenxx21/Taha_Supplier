# Flutter Client Cart Module Documentation

## Base URL
All endpoints are relative to the application's base URL (e.g. `http://localhost:3000`).

## Global Rules
- **Authentication:** All requests must include a valid Bearer token for a user with the `CLIENT` role. The user's ID is automatically extracted from the token to find or create their specific cart.
- **Response Format:** All responses are intercepted and wrapped in a standard format:
  ```json
  {
    "message": "Success", // or error message
    "data": <actual_response_data>
  }
  ```

---

## Cart Endpoints

### 1. Get My Cart
**Endpoint:** `GET /cart`
**Roles:** `CLIENT`

Fetches the authenticated user's cart. If the user does not have a cart yet, an empty one is automatically created. This endpoint computes the `effective_price` (favoring `discount_price` over original `price`), the `line_total` for each item, and the overall `subtotal`, `discount_amount`, and `total` price of the cart. It also dynamically validates any attached coupon and returns metadata.

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": {
    "id": 1,
    "user_id": 1,
    "coupon_id": null,
    "created_at": "2026-09-19T00:00:00.000Z",
    "updated_at": "2026-09-19T00:00:00.000Z",
    "items": [
      {
        "id": 10,
        "cart_id": 1,
        "product_id": 5,
        "quantity": 2,
        "created_at": "2026-09-19T00:00:00.000Z",
        "updated_at": "2026-09-19T00:00:00.000Z",
        "product": {
          "id": 5,
          "name": "Headphones",
          "price": 100.00,
          "discount_price": 80.00,
          "is_available": true
          // ... full product fields
        },
        "effective_price": 80,
        "line_total": 160
      }
    ],
    "coupon_valid": null,
    "coupon_invalid_reason": null,
    "subtotal": 160,
    "discount_amount": 0,
    "total": 160
  }
}
```
*Note: If `coupon_valid` is `false`, check `coupon_invalid_reason` to explain why the coupon was rejected (e.g. expired, minimum amount not met, etc).*

### 2. Add Item to Cart
**Endpoint:** `POST /cart/items`
**Roles:** `CLIENT`
**Content-Type:** `application/json`

Adds a product to the user's cart. If the product is already in the cart, this endpoint will simply increment the existing quantity by the provided amount.

**Request Body (JSON):**
- `product_id` (number, required, min 1): The ID of the product to add.
- `quantity` (number, required, min 1): The quantity to add.

**Example Request:**
```json
{
  "product_id": 5,
  "quantity": 2
}
```

**Success Response (201 Created):**
```json
{
  "message": "Success",
  "data": {
    "id": 10,
    "cart_id": 1,
    "product_id": 5,
    "quantity": 2,
    "created_at": "2026-09-19T00:00:00.000Z",
    "updated_at": "2026-09-19T00:00:00.000Z",
    "product": {
      // ... full product object
    }
  }
}
```

**Errors:**
- `404 Not Found`: "Product not found" (If `product_id` is invalid).
- `409 Conflict`: "Product is not available" (If `is_available` is false for the product).

### 3. Update Cart Item Quantity
**Endpoint:** `PATCH /cart/items/:id`
**Roles:** `CLIENT`
**Content-Type:** `application/json`

Updates the quantity of a specific cart item. The URL requires the **Cart Item ID**, not the Product ID.

**Request Parameters:**
- `id` (number in URL): The **Cart Item ID** to update.

**Request Body (JSON):**
- `quantity` (number, required, min 1): The new exact quantity for this cart item.

**Example Request:**
```json
{
  "quantity": 5
}
```

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": {
    "id": 10,
    "cart_id": 1,
    "product_id": 5,
    "quantity": 5,
    "created_at": "2026-09-19T00:00:00.000Z",
    "updated_at": "2026-09-19T00:00:00.000Z",
    "product": { ... }
  }
}
```

**Errors:**
- `404 Not Found`: "Cart item not found" (If the item doesn't exist or belongs to another user).
- `404 Not Found`: "Product not found"
- `409 Conflict`: "Product is not available"

---

### 4. Remove Item from Cart
**Endpoint:** `DELETE /cart/items/:id`
**Roles:** `CLIENT`

Removes a specific item completely from the user's cart. The URL requires the **Cart Item ID**, not the Product ID.

**Request Parameters:**
- `id` (number in URL): The **Cart Item ID** to delete.

**Success Response (200 OK):**
```json
{
  "message": "Success",
  "data": {
    "deleted": true
  }
}
```

**Errors:**
- `404 Not Found`: "Cart item not found" (If the item doesn't exist or belongs to another user's cart).

---

### 5. Apply Coupon
**Endpoint:** `POST /cart/apply-coupon`
**Roles:** `CLIENT`
**Content-Type:** `application/json`

Applies a discount coupon to the cart. If successful, this endpoint will return the fully updated cart with `coupon_valid: true`, `subtotal`, `discount_amount`, and `total`.

**Request Body (JSON):**
- `code` (string, required): The coupon code to apply.

**Example Request:**
```json
{
  "code": "SUMMER10"
}
```

**Success Response (201 Created):**
```json
{
  "message": "Success",
  "data": {
    "id": 1,
    "user_id": 1,
    "coupon_id": 2,
    "created_at": "2026-09-19T00:00:00.000Z",
    "updated_at": "2026-09-19T00:00:00.000Z",
    "items": [ ... ],
    "coupon_valid": true,
    "coupon_invalid_reason": null,
    "subtotal": 160,
    "discount_amount": 16,
    "total": 144
  }
}
```

**Errors:**
- `404 Not Found`: "Coupon not found"
- `409 Conflict`: "Coupon is paused or inactive"
- `409 Conflict`: "Coupon is not active yet"
- `409 Conflict`: "Coupon has expired"
- `409 Conflict`: "Coupon usage limit reached"
- `409 Conflict`: "Minimum order amount of X not met"
- `409 Conflict`: "You have already used this coupon"

---

### 6. Remove Coupon
**Endpoint:** `POST /cart/remove-coupon`
**Roles:** `CLIENT`

Removes any currently attached coupon from the user's cart. Returns the updated cart with reset totals.

**Success Response (201 Created):**
```json
{
  "message": "Success",
  "data": {
    "id": 1,
    "user_id": 1,
    "coupon_id": null,
    "created_at": "2026-09-19T00:00:00.000Z",
    "updated_at": "2026-09-19T00:00:00.000Z",
    "items": [ ... ],
    "coupon_valid": null,
    "coupon_invalid_reason": null,
    "subtotal": 160,
    "discount_amount": 0,
    "total": 160
  }
}
```
